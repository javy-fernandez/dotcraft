# B-22 Resolved NuGet dependency graph: .NET 8/Linux acceptance

## Behavior and provenance

DotCraft reads the `project.assets.json` emitted by a successful `dotnet restore` and builds a graph of resolved package versions. Direct packages come from the project's framework dependencies; edges come from the resolved target's package dependencies. Project and framework references are excluded. The NuGet tool window has a **Dependency graph** tab with a project selector and expandable package dependency rows. Assets are read on a blocking worker, away from the UI thread.

This implementation uses the restore format generated by Microsoft's official .NET SDK 8.0.428 and a temporary copy of the repository's Shop fixture. No third-party code or assets are copied. The test writes a temporary `NuGet.Config` that clears package sources, and restore succeeds from the pre-existing local package cache without a live feed.

## Validation

With `DOTCRAFT_TEST_DOTNET=/var/tmp/dotcraft-dotnet/dotnet`, `DOTNET_ROOT=/var/tmp/dotcraft-dotnet`, `NUGET_PACKAGES=/var/tmp/dotcraft-cli-home/.nuget/packages`, an isolated `DOTNET_CLI_HOME`, and `CARGO_TARGET_DIR=/var/tmp/dotcraft-nuget-graph-live-target`:

```text
cargo test -p rc-dotnet nuget_assets -- --include-ignored --nocapture
cargo test -p rc-dotnet --test nuget_assets_live -- --ignored --nocapture
cargo test -p rc-app dependency_graph_tab_shows_resolved_shop_edges -- --ignored --nocapture
cargo test -p rc-dotnet --lib --quiet
```

The live backend test restores Shop.Api and verifies its direct `Swashbuckle.AspNetCore` reference, the resolved Swagger dependency, and the transitive `Microsoft.OpenApi` edge. The app test restores all six Shop projects, opens the new tab, selects Shop.Api, expands the direct package, and checks the resolved dependency labels. Parser tests cover project-reference exclusion, malformed assets, and the 16 MiB input bound.

## Limits

The view represents the first matching target framework in the restored assets and requires a prior successful restore. It displays package-to-package dependencies only. Runtime-specific targets, multi-target selection, package metadata, graph layout, and platforms or SDK versions other than .NET 8/Linux remain unverified. PR #216 separately adds a static direct graph for projects without restore assets; it is not included here.
