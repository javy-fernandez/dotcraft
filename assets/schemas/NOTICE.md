# Bundled JSON schemas

`appsettings.json` is the JSON schema for ASP.NET Core's `appsettings*.json` files from
[SchemaStore](https://github.com/SchemaStore/schemastore)
(`src/schemas/json/appsettings.json`, published at <https://json.schemastore.org/appsettings.json>),
bundled unchanged so completion and validation work offline.
